Installer r2modman

Extrais le zip, puis lance r2modman Setup 3.2.19.exe.

Télécharger r2modman

Si une page s'ouvre, clique Download. Install with App, c'est l'autre programme.

Choisir R.E.P.O.

Ouvre r2modman, cherche R.E.P.O., clique dessus.

Importer le pack

  1. Import / Update.
  2. Import new profile.
  3. From code.
  4. Colle le code du pack, puis Continue.

    Code du pack

    01a0ce07-04d2-94af-b09d-c3f918f4d018
  5. Clique Import.
  6. Choisis un nom, puis Create.
  7. Attends la fin. Ne ferme pas r2modman.
  8. Clique le profil, puis Select profile.
  9. Start modded, en haut à gauche.

Installer Thunderstore Mod Manager

Ça installe Overwolf, puis le programme.

Télécharger Thunderstore Mod Manager

Choisir R.E.P.O.

Ouvre Thunderstore Mod Manager. Cherche R.E.P.O. et clique Select game.

Importer le pack

  1. Import / Update.
  2. Import new profile.
  3. From code.
  4. Colle le code du pack, puis Continue.

    Code du pack

    01a0ce07-04d2-94af-b09d-c3f918f4d018
  5. Clique Import.
  6. Choisis un nom, puis Create.
  7. Attends la fin du téléchargement. Ne ferme pas le programme.
  8. Clique le profil, puis Select profile.
  9. Modded, en haut à droite.
